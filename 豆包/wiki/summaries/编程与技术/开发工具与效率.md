# 开发工具与效率

来源：[[豆包/raw/编程与技术/开发工具与效率]]

> 这组对话是日常开发环境与效率工具的"手册集合"：Git 工作流（clone 改远程、rebase、合并 commit、clone 失败排查）、Node/npm/yarn/nvm 版本与全局包管理、macOS 命令行与 AppleScript 自动化、文本正则与 Word/WPS 排版论文、跨平台字体渲染差异，以及一批快捷键与效率插件。

## 核心要点
- Git 高频操作三组：① 克隆后改成自己的仓库——`git remote remove origin` 再 `git remote add origin <新地址>`，或直接 `git remote set-url origin <新地址>`；② clone 报 `RPC failed; curl 92 ... early EOF`——调大 `http.postBuffer`（如 524288000）、`--depth 1` 浅克隆、`fetch.parallel 1` 降并行、检查代理与网络、升级 Git；③ 合并零散 commit——`git rebase -i <父提交或 HEAD~n>`，前缀改成 `squash`（保留可编辑 message）或 `fixup`（丢弃 message），完成后 `--continue`，已推送分支用 `--force-with-lease`，公共分支禁止变基。
- rebase 的本质：把当前分支的提交依次"重放"到目标分支最新提交之后，让历史线性清晰，但会改变 commit 哈希，协作分支上使用需谨慎；冲突时 `git add` 后 `git rebase --continue`，放弃用 `--abort`。
- Node 版本与包管理：nvm 用 `nvm install/use/list-remote` 管理版本，`nvm alias default 18` 设默认；LTS 比非 LTS 更稳；全局包安装目录决定命令是否可被找到——路径需在 PATH 中，`npm config get prefix`、`yarn global bin` 查目录，`which`（Windows `where`）查命令来源。
- npm 与 yarn 装了同名全局包时，由 PATH 中路径先后顺序决定执行哪个；可靠做法是用完整路径执行，或卸载其一（`npm uninstall -g` / `yarn global remove`）；`yarn global list` / `npm list -g --depth 0` 查看全局包，`yarn config get registry` 查镜像源。
- macOS 命令行自动化：`defaults write com.apple.finder/dock ...` + `killall Finder/Dock` 改系统设置；`&>/dev/null &` 表示 stdout+stderr 都丢进位桶并在后台运行；`nohup ... &` 后台执行不弹终端；`osascript` 配合 AppleScript 显示通知或 `close (every window whose visible is true) without saving` 免确认关闭窗口。
- 文本与正则：正则匹配回车用 `\r` 或 `\r\n`（Windows）与 `\n`（Unix），匹配 `<!--ID: \d+-->` 这类注释；Word 自带"使用通配符"可做 `^13([^:]*)` 之类的近似替换，真正正则需写 VBScript.RegExp 的 VBA 宏。
- 论文排版：回车分页不可行（增删文字即错乱、目录页码失效、不符合规范），必须用分页符（Ctrl+Enter）或段落设置"段前分页"；章节距页首不一致的高频原因是分节符与分页符混用、页首段前间距被"吞掉"规则、标题样式不统一、页面/文档网格设置不一致，修复顺序是显示编辑标记 → 统一页边距与网格 → 统一标题样式 → 规范分页。
- 跨平台字体差异：macOS（Core Text/Quartz）几乎不做 hinting、灰度抗锯齿、忠于原字形（偏粗偏柔），Windows（ClearType/DirectWrite）强 hinting、对齐像素网格（偏细偏锐）；SimSun 与华文宋体（STSong）是两个字体文件，Mac 上"宋体"会被替换；统一办法是 Mac 装 `simsun.ttc`、改用思源黑体/思源宋体等跨平台字体、关闭 WPS 字体平滑并选"兼容 Windows"渲染模式，定稿转 PDF。
- 效率工具与快捷键：Prettier 失效先查插件版本/配置/`.prettierrc`/项目覆盖；IDEA 双击 Shift 是 Search Everywhere，Ctrl/⌘+Shift+F 是 Find in Path；Safari 开发者工具 macOS 为 ⌘+Option+I；Vim 撤销 `u`、恢复 `Ctrl+r`、恢复整行 `U`；Fn 键解锁前后 F1–F12 默认行为相反；沉浸式翻译/沙拉查词/彩云小译等免费双语对照插件；MarginNote、NotebookLM、小绿鲸等"左侧脑图 + 右侧原文"的 AI 阅读工具。

## 值得回看的问答
- **commit 太多，如何分割下，我应该如何合并主题？**：用 `git rebase -i HEAD~n` 把同主题 commit 前缀改为 `squash`（无意义小修复用 `fixup`），保留一个 `pick` 作主提交并重写 message；公共分支不要变基，变基前可先建临时分支备份。
- **git 如何快速克隆一个项目到本地并切换为自己的仓库？**：clone → 进目录 → `git remote remove origin` → 在自己平台新建仓库 → `git remote add origin <新地址>` → `git push -u origin master`。
- **mac 的 wps 字体和 win 字体为什么会有区别？（主要是明朝字体的差别）**：字体文件不同（SimSun vs 华文宋体）+ 渲染引擎方向相反（强 hinting 变细变锐 vs 灰度抗锯齿变粗变柔）+ WPS 在 Mac 上字重匹配与行距计算偏 Windows。
- **回车分页行吗？为什么我的章节第一章和第二章距离页首不一样？**：不可行；差异来自分节/分页混用、段前间距被吞规则、标题样式与页面设置不统一，需按"清标记 → 统一样式与页边距 → 用分页符"三步修复。
- **在 yarn 和 npm 中均安装了同一个全局包，运行的是哪个？如何查看自己可以使用的全局命令？**：由 PATH 顺序决定，推荐完整路径执行或卸载其一；用 `which`/`where` 定位命令来源，`echo $PATH` 配合 `ls` 浏览可执行目录。
- **`&>/dev/null &` 用处是什么？执行后怎么自动关闭 terminal 而不需要确认？**：把 stdout/stderr 重定向到 /dev/null 并后台运行；用 AppleScript 的 `close (every window whose visible is true) without saving` 免确认关闭窗口。
