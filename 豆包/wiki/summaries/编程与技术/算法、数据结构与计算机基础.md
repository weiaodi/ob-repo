# 算法、数据结构与计算机基础

> 这组对话覆盖两条线：一是手写题（排序、二分、前缀和、LIS、轮转数组、链表判环、回溯、A*），二是计算机基础原理（时间复杂度推导、反码补码、浮点数精度、编译原理、操作系统调度）。其中大量内容来自课程实验与课程作业（递归实验、银行家算法、时间片轮转），带有明确的教学语气。

## 核心要点
- 建堆两种方式复杂度不同：逐个插入用上浮是 O(n log n)，把无序数组从最后一个非叶子节点开始下沉是 O(n)；堆在结构上可用完全二叉树表示，通常用数组存储，也可用对象/链表。
- 红黑树五条性质（节点红黑、根黑、叶黑、红节点子节点必黑、黑高相等）保证树高对数级，查找/插入/删除均为 O(log n)。
- 前缀和把区间求和从 O(n) 降到 O(1)：`prefix[i]` 表示 0..i 的和，区间 [left, right] = `prefix[right] - prefix[left-1]`。
- 快速选择是快排变体，只递归一半子数组，平均 O(n)、最坏 O(n²)；因为不需要像快排那样处理两侧，所以不是 O(n log n)。
- O(n log n) 的来源：分治层数 log n × 每层线性合并 O(n)，可用递推展开或主定理（T(n)=2T(n/2)+O(n)）证明。
- LIS 三种解法：暴力枚举 O(2ⁿ·n)、动态规划 O(n²)、二分维护 tails 数组 O(n log n)。
- 反码/补码的意义是把减法转成加法（配合同余原理，n 位二进制等价于对 2ⁿ 取模），从而只需一套加法器电路。
- IEEE 754 双精度浮点是 64 位（1 符号 + 11 指数 + 52 尾数），所以 JS 中数字最小存储单位是 8 字节；浮点数换来更大表示范围与小数能力，牺牲的是部分精度（尾数位有限）。
- 编译原理主干：词法分析 → 语法分析 → 语义分析 → 中间代码生成 → 代码优化 → 目标代码生成；JS 引擎里对应 V8 的 Ignition 字节码与 TurboFan 优化编译。
- A* = BFS + 启发函数 f(n)=g(n)+h(n)；h(n)=0 时退化成 BFS，h(n) 满足可采纳性时既能加速又保证最短路径。

## 值得回看的问答
- **上升堆和下降堆的优缺点**：上浮适合动态逐个插入（O(n log n) 建堆），下沉适合批量把数组建成堆（O(n)），且取堆顶后恢复性质更快。
- **线性对数阶的时间复杂度如何计算得出？**：分治 log n 层、每层合并 O(n)，由递推 T(n)=2T(n/2)+O(n) 展开或主定理得 O(n log n)。
- **计算机中为什么引入反码来做运算**：为了把减法转成加法，简化运算电路；数学基础是模 2ⁿ 的同余，负数用反码加 1 得补码。
- **浮点数为什么比整数的精度大，他牺牲了什么？**：准确说是表示范围更大且能表示小数（指数位扩展范围），牺牲的是尾数精度——大整数无法精确表示。
- **快速选择，算法最坏情况和平均情况**：最坏 O(n²)（每次划分都极不均匀），平均 O(n)（每次只处理划分后的一半，T(n)=T(n/2)+O(n)）。
- **a星和bfs之间的效率区别是什么**：h(n)=0 时 A* 完全退化成 BFS，效率一样；优质启发函数下 A* 扩展节点远少于 BFS，但要保证可采纳性才能保证最短路径。
