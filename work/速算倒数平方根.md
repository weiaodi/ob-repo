# 快速倒数平方根（Q_rsqrt）详细推导过程
Q_rsqrt是经典的**浮点数位级hack算法**，核心通过**IEEE 754浮点数格式特性**+**牛顿迭代法**实现平方根倒数的快速近似计算，比直接计算`1.0/sqrt(x)`快一个数量级，是《雷神之锤3》的经典优化代码，以下从底层原理到完整推导逐步拆解。

## 一、前置基础：IEEE 754 32位单精度浮点数格式
要理解算法的位级操作，必须先掌握32位float的标准存储格式，这是整个算法的**数学基础**。
32位float将二进制位划分为3部分（共32位）：

| 符号位S（1位） | 指数位E（8位） | 尾数位M（23位） |
|----------------|----------------|----------------|
| 0=正/1=负      | 偏移指数（偏置127） | 隐含前导1的小数 |

### 浮点数的数值表示公式
对于**正浮点数**（平方根倒数仅处理正数，S=0），其实际数值为：
$$ x = (1 + M) \times 2^{E - 127} $$
其中：
- 指数位E：无符号8位整数，范围`0~255`，实际指数需要**减去偏置127**（解决负指数问题）；
- 尾数位M：23位二进制小数，取值范围`0 ≤ M < 1`，隐含**前导1**，因此尾数整体范围是`1 ≤ 1+M < 2`（规范化浮点数）。

### 关键：浮点数的整数位表示转换
算法中核心操作`i = * (long *) &y`是将float的**二进制位直接解释为32位有符号长整型**，设该整型值为$I(x)$，则$I(x)$与浮点数$x$的指数E、尾数M的关系为：
$$ I(x) = E \times 2^{23} + M \times 2^{23} $$
（指数位占高8位，尾数位占低23位，直接拼接为整型）

## 二、核心目标与对数变换：将乘除转为加减
算法要计算的是**平方根的倒数**，即对于输入$x>0$，求：
$$ f(x) = \frac{1}{\sqrt{x}} = x^{-1/2} $$

直接对浮点数做位操作无法实现幂运算，因此引入**自然对数/指数变换**，利用对数的**降幂特性**将幂运算转为乘除，再转为加减（位操作的本质是二进制加减）：
对等式两边取自然对数：
$$ \ln(f(x)) = \ln(x^{-1/2}) = -\frac{1}{2} \ln(x) $$
再对两边取指数还原：
$$ f(x) = e^{ -\frac{1}{2} \ln(x) } $$

这一步的核心价值：将“平方根倒数”这个**非线性幂运算**，转化为**对数的线性运算**+指数还原，为后续位级线性近似铺路。

## 三、浮点数的对数线性近似（核心推导）
### 1. 对浮点数公式取对数
由$x = (1 + M) \times 2^{E - 127}$，取自然对数得：
$$ \ln(x) = \ln(1+M) + (E - 127) \ln2 $$
令常数$L = \ln2$，$B = 127$，则简化为：
$$ \ln(x) = \ln(1+M) + (E - B) L $$

### 2. 对数的线性近似（关键近似）
尾数$M \in [0,1)$，因此$1+M \in [1,2)$，对$\ln(1+M)$做**一阶线性近似**（用直线逼近曲线，牺牲微小精度换取计算效率）：
$$ \ln(1+M) \approx a \cdot M + b $$
其中$a、b$为拟合常数（算法中通过实验确定最优值）。

将该近似代入上式，整理得：
$$ \ln(x) \approx aM + b + EL - BL $$
$$ \ln(x) \approx L \cdot E + a \cdot M + (b - BL) $$

### 3. 关联浮点数的整型位表示$I(x)$
由$I(x) = E \times 2^{23} + M \times 2^{23} = 2^{23}(E + M)$，令常数$K = 2^{23}$（32位float尾数位的权重，固定值$8388608$），则：
$$ E + M = \frac{I(x)}{K} $$

将$E = \frac{I(x)}{K} - M$代入$\ln(x)$的近似式，最终可推导出**浮点数对数与其整型位表示$I(x)$的线性关系**：
$$ \ln(x) \approx \alpha \cdot I(x) + \beta $$
其中$\alpha、\beta$为**综合拟合常数**（由$L、a、b、K、B$共同决定，是实验优化后的固定值）。

这是整个算法的**核心结论**：**正浮点数的自然对数，与其IEEE 754格式的二进制位所表示的整型值，呈近似线性关系**。
正是这个线性关系，让我们可以通过**整型位的加减操作**，实现对数的快速计算，而无需复杂的浮点运算。

## 四、位级魔术：0x5f3759df - (i >> 1) 的推导
基于上述线性关系，推导平方根倒数的整型位表示，这一步是算法的“魔术核心”。

### 1. 目标值的对数线性关系
设目标值$y = \frac{1}{\sqrt{x}} = x^{-1/2}$，对$y$应用同样的对数线性近似，得：
$$ \ln(y) \approx \alpha \cdot I(y) + \beta $$

### 2. 结合原数与目标数的对数关系
由之前的对数变换结论：$\ln(y) = -\frac{1}{2} \ln(x)$，将原数和目标数的线性近似代入得：
$$ \alpha \cdot I(y) + \beta = -\frac{1}{2} \left( \alpha \cdot I(x) + \beta \right) $$

### 3. 解目标数的整型位表示$I(y)$
将上式整理，解出$I(y)$（唯一的未知量）：
$$ \alpha \cdot I(y) = -\frac{1}{2}\alpha \cdot I(x) - \frac{1}{2}\beta - \beta $$
$$ \alpha \cdot I(y) = -\frac{\alpha}{2} \cdot I(x) - \frac{3\beta}{2} $$
两边同时除以$\alpha$（$\alpha \neq 0$）：
$$ I(y) = -\frac{1}{2} I(x) - \frac{3\beta}{2\alpha} $$

### 4. 转化为计算机位操作
计算机中**有符号整数的除以2**，等价于**算术右移1位**（`i >> 1`），因此$-\frac{1}{2}I(x)$对应位操作`- (I(x) >> 1)`；

令常数$C = -\frac{3\beta}{2\alpha}$，则公式简化为：
$$ I(y) = C - (I(x) >> 1) $$

### 5. 魔术常数0x5f3759df的由来
常数$C = -\frac{3\beta}{2\alpha}$是**实验拟合的最优值**，并非理论推导的精确值：
- 算法作者通过大量测试，发现当$C$取十六进制`0x5f3759df`（十进制约1597463007）时，位级近似的结果与真实值误差最小；
- 这个值是**工程优化的产物**，是对$\alpha、\beta$等拟合常数的综合最优选择，也是该算法最巧妙的地方。

这就解释了代码中`i = 0x5f3759df - (i >> 1);`的本质：通过整型位操作，直接计算出目标值$y=1/\sqrt{x}$的IEEE 754整型位表示$I(y)$。

## 五、牛顿迭代法：迭代修正，提升精度
位级近似的结果存在微小误差（约1%~2%），代码中通过**牛顿迭代法**对近似值进行1次修正，将精度提升到**机器精度级别**（满足绝大多数工程场景），这是算法的最后一步。

### 1. 确定牛顿迭代的目标函数
我们要解的方程是：$\frac{1}{y^2} = x$（等价于$y=1/\sqrt{x}$），整理为**求根函数**（令$f(y)=0$）：
$$ f(y) = \frac{1}{y^2} - x = 0 $$

### 2. 牛顿迭代公式推导
牛顿迭代法的核心是**用切线逼近曲线**，迭代公式为：
$$ y_{n+1} = y_n - \frac{f(y_n)}{f'(y_n)} $$
其中$f'(y)$是$f(y)$的一阶导数。

对$f(y) = 1/y^2 - x$求导：
$$ f'(y) = -\frac{2}{y^3} $$

将$f(y_n)$和$f'(y_n)$代入迭代公式，化简：
$$ y_{n+1} = y_n - \frac{\frac{1}{y_n^2} - x}{-\frac{2}{y_n^3}} $$
$$ y_{n+1} = y_n + \frac{y_n^3 (\frac{1}{y_n^2} - x)}{2} $$
$$ y_{n+1} = y_n + \frac{y_n - x y_n^3}{2} $$
提取公因子$y_n/2$，最终得到**简化的牛顿迭代公式**：
$$ y_{n+1} = y_n \cdot \left( \frac{3}{2} - \frac{x}{2} \cdot y_n^2 \right) $$

### 3. 对应代码中的迭代实现
代码中定义了常数`threehalfs = 1.5F`（即$3/2$），`x2 = number * 0.5F`（即$x/2$），因此迭代公式在代码中直接体现为：
```c
y = y * ( threehalfs - ( x2 * y * y ) );   // 1st iteration
```

### 4. 迭代次数的选择
- 1次迭代：将位级近似的误差从约1%缩小到**10^-6级别**，满足几乎所有实时计算场景（如游戏、图形渲染）；
- 2次迭代：误差可缩小到**10^-12级别**，接近32位float的机器精度（float有效精度约6~7位十进制），但代码中注释掉了，因为1次迭代的精度已足够，额外迭代会增加计算开销。

## 六、完整算法流程梳理（结合代码）
将上述推导整合，代码的每一步操作都对应明确的数学原理，完整流程如下：
```c
float Q_rsqrt( float number )  // 输入x>0，求1/sqrt(x)
{
    long i;
    float x2, y;
    const float threehalfs = 1.5F;  // 牛顿迭代的3/2常数

    x2 = number * 0.5F;  // 计算x/2，为牛顿迭代做准备
    y  = number;         // 保存输入x的浮点数副本
    i  = * ( long * ) &y; // 核心1：将x的float位表示转为整型I(x)（位级拷贝，无数值转换）
    i  = 0x5f3759df - ( i >> 1 ); // 核心2：位级近似计算I(y)=C - I(x)/2
    y  = * ( float * ) &i; // 核心3：将整型I(y)转回float，得到y的近似值
    y  = y * ( threehalfs - ( x2 * y * y ) ); // 核心4：1次牛顿迭代，修正近似值
    return y; // 输出高精度的1/sqrt(x)
}
```

## 七、关键补充说明
1. **位操作的安全性**：代码中`*(long*)&y`是**未定义行为**（严格C标准中，不同类型的指针强制转换可能导致内存对齐/别名问题），但在x86等主流架构中，float和long都是4字节，实际运行稳定，这是工程上的“hack”取舍；
2. **适用范围**：仅支持**正的规范化32位float**（S=0，E≠0且E≠255），对0、无穷大、NaN无效；
3. **精度与效率**：位级近似+1次牛顿迭代，耗时仅为直接计算`1.0/sqrtf(x)`的1/10左右，精度满足工程需求（相对误差<1e-6）；
4. **魔术常数的变体**：后续有研究者发现`0x5f375a86`比`0x5f3759df`的近似误差更小，但`0x5f3759df`是《雷神之锤3》的原版实现，更具标志性。

## 总结
Q_rsqrt算法的精妙之处在于**理论数学**与**工程优化**的完美结合，核心推导可归纳为3个关键步骤：
1. 利用**IEEE 754浮点数格式**，建立浮点数与其二进制位整型表示的关联；
2. 通过**对数线性近似**，将平方根倒数的幂运算转化为整型位的加减操作，推导出位级近似公式$I(y)=C - I(x)/2$；
3. 用**牛顿迭代法**对近似值进行1次修正，将精度提升到工程可用级别。

整个算法避开了复杂的浮点开方和除法运算，仅通过简单的位操作和浮点乘加实现，是经典的“以空间换时间”、“以微小精度损失换极致效率”的优化典范。
