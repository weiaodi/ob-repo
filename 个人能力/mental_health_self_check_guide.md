# 常见心理因素与心理健康自查指南

版本：2026-10-14  
适用对象：希望系统观察自身心理状态的成年人  
资料性质：心理健康教育和风险识别；不是诊断、治疗方案或医疗意见

> 自查不是给自己贴疾病标签，而是回答三个问题：最近出现了什么变化？这些变化造成多大影响？应该继续观察、预约专业评估，还是立即求助？

精神科和临床心理评估不会只看“有没有某个症状”，而会综合考虑症状组合、持续时间、病程变化、功能损害、现实检验能力、安全风险，以及药物、物质使用和躯体疾病等其他解释。

## 一、先排查需要立即处理的情况

出现以下任意一项时，不要继续依赖自测量表，也不要独处硬扛：

- 正在考虑自杀、自伤或伤害他人，或已经形成具体计划。
- 已经准备工具、药物，安排告别或处理遗物。
- 听见命令自己伤人或自伤的声音。
- 明显无法分辨现实与想象，出现强烈被害感、被控制感。
- 连续多日几乎不睡但精力异常旺盛，同时冲动消费、冒险或做重大决定。
- 极度激越、行为失控，本人或身边人无法保证安全。
- 因心理状态停止进食、饮水或基本自理。
- 自伤、服药过量或其他危险行为已经发生。

### 应对顺序

1. 有迫在眉睫的危险时，拨打 120 或 110，或立即前往综合医院急诊、精神专科急诊。
2. 不要独处，联系一个可信任的人陪同。
3. 在能够安全做到的前提下，暂时移开大量药物、刀具、绳索及其他危险物品。
4. 全国统一心理援助热线为 12356，可提供心理疏导和危机干预，但不能替代急救。

NICE 自伤指南强调：不能依靠风险量表预测某个人是否会自杀，也不能用“低、中、高风险”分类决定是否提供治疗。[R01]

## 二、自查的五条基本判断轴

遇到任何心理现象，先完成以下五项判断，不要先搜索疾病名称。

### 1. 与个人基线相比是否改变

- 与平时的自己相比是否明显不同？
- 熟悉自己的人是否也发现了变化？
- 是长期如此，还是近期突然出现？
- 变化主要发生在睡眠、精力、情绪、思维还是行为？

一个人长期少言不一定是抑郁；原本稳定的人突然退缩、失眠、失去兴趣，更值得注意。判断重点是“相对个人基线的变化”，不是与别人比较。

### 2. 持续时间和频率

- 首次出现的日期和背景。
- 一天持续多久，一周出现几天。
- 持续存在还是阵发出现。
- 是否具有周期性、季节性，或与月经周期相关。
- 中间有没有完全恢复到平时状态。
- 最近是改善、稳定还是加重。

“因为争吵难受两小时”和“连续两周大部分时间低落”不能作同样解释。

### 3. 主观痛苦程度

- 0—3：可以承受，不明显干扰生活。
- 4—6：反复占用注意力，需要额外努力才能维持生活。
- 7—10：难以控制，明显痛苦或接近失控。

这个分数不是诊断阈值，只用于观察自己的变化趋势。

### 4. 功能损害

| 领域 | 观察问题 |
|---|---|
| 学习或工作 | 效率、出勤、错误率、拖延和决策能力是否改变？ |
| 生活自理 | 饮食、卫生、购物、做饭和整理环境是否受影响？ |
| 人际关系 | 是否明显回避、争吵、过度依赖、猜疑或失控表达？ |
| 睡眠 | 入睡、夜醒、早醒、总睡眠时间和白天困倦是否改变？ |
| 风险判断 | 消费、投资、驾驶、性行为和网络行为是否更冲动？ |
| 兴趣与参与 | 是否放弃原本重要或能够带来满足感的活动？ |

功能损害通常比一个孤立症状更能说明是否需要专业帮助。

### 5. 安全性与现实检验

- 能否区分“这是我的担心”和“这已经被事实证明”？
- 能否推迟冲动行为并理解后果？
- 是否出现自伤、攻击、严重冒险或自我忽视？
- 是否愿意听取可信任者的反馈？
- 是否发现别人普遍无法理解或观察到自己坚信的体验？

## 三、常见心理症状群自查

不同症状群可以同时出现。以下内容用于识别进一步评估的方向，不用于自行确诊。

### 1. 抑郁相关症状

观察近两周是否反复出现：

- 持续低落、空虚、麻木或明显易怒。
- 对原来喜欢的事情失去兴趣或快感。
- 精力下降，日常小事也觉得困难。
- 明显自责、无价值感、无望感。
- 注意力、记忆或决策能力下降。
- 入睡困难、早醒、嗜睡或昼夜颠倒。
- 食欲或体重明显变化。
- 动作和思考变慢，或者坐立不安。
- 反复想到死亡、自伤或“消失就好了”。

需要区分：正常悲伤通常与具体失落有关，情绪会波动；抑郁也可能表现为愤怒、身体不适或社交退缩。甲状腺疾病、贫血、慢性疼痛、睡眠障碍、药物副作用和物质使用都可能产生类似表现。如果过去曾有躁狂或轻躁狂表现，不能只按“单纯抑郁”理解。

NIMH 指出，重性抑郁通常涉及至少两周的大部分时间出现低落或兴趣丧失，并造成显著痛苦或功能损害；只有部分症状的人也可能从专业帮助中受益。[R02]

### 2. 广泛焦虑与慢性担忧

- 对多个生活领域反复担心，而非只有一个具体问题。
- 明知担心可能过度，却很难停下来。
- 反复预演最坏结果、查资料或向别人寻求保证。
- 肌肉紧张、头痛、胃肠不适、心慌。
- 易疲劳、易怒、注意力被担忧占据。
- 睡前思绪无法停止，或因担忧拖延决定、回避行动。

有现实依据、能够促使问题解决的担忧，不等于病理性焦虑。咖啡因、尼古丁、兴奋剂、甲状腺问题、心律异常和睡眠不足也可能加重焦虑。临床评估还会检查持续时间、功能损害、其他精神症状、物质使用和身体疾病。[R03]

### 3. 惊恐发作

典型表现是在短时间内迅速出现：

- 强烈恐惧、濒死感或失控感。
- 心跳加速、胸闷、呼吸困难。
- 出汗、发抖、头晕、麻木。
- 感觉环境不真实，或感觉自己与身体分离。
- 随后持续担心再次发作，并开始回避某些场所。

第一次出现严重胸痛、呼吸困难、晕厥或明显身体症状时，应先进行医疗评估，不能自行认定只是惊恐发作。

### 4. 社交焦虑

- 强烈害怕被审视、出丑或遭到否定。
- 会前长时间预演，会后反复复盘。
- 回避发言、聚会、约会、打电话或公开进食。
- 明知实际危险不大，身体仍出现强烈焦虑。
- 回避已经限制学习、工作或关系。

内向是社交偏好；社交焦虑的关键是恐惧、回避、主观痛苦和功能受限。

### 5. 强迫相关表现

- 出现不想要、令人痛苦的侵入性想法、冲动或画面。
- 为减轻焦虑，反复检查、清洁、计数、确认或回忆。
- 存在必须按照特定顺序完成的仪式。
- 明知行为可能过度，但不做就非常不安。
- 每天耗费大量时间，影响出门、学习、睡眠或关系。

喜欢整洁或认真谨慎不等于强迫症。侵入性想法也不等于真实意图，需要分别评估本人是否准备实施行为。不断寻求百分之百确定可能本身就是维持强迫的因素。

### 6. 创伤与应激反应

在经历或目睹死亡威胁、严重伤害、暴力、性侵或重大事故等事件后，观察：

- 不由自主地回想、做噩梦或出现闪回。
- 回避相关地点、人物、话题或感受。
- 持续警觉、易惊、易怒、难以入睡。
- 感到麻木、疏离、自责或世界不再安全。
- 特定声音、气味、日期会触发强烈反应。
- 感觉事情正在重新发生，而不只是普通回忆。

事件后的短期应激反应不自动等于 PTSD。创伤类型、持续时间、症状组合和功能损害都需要评估。PC-PTSD-5 是初级筛查工具，筛查阳性后仍需要进一步访谈。[R04]

### 7. 躁狂或轻躁狂线索

- 睡眠明显减少，却不觉得困。
- 情绪异常高涨，或比平时明显易怒。
- 讲话加快，很难被打断。
- 思维飞快，同时启动很多项目。
- 自我评价异常膨胀，感觉能力、地位或意义特殊。
- 消费、借贷、投资、驾驶或性行为明显更冒险。
- 熟悉的人认为本人“完全不像平时”。
- 行为已经造成后果，但本人当时坚信自己没有问题。

普通高效率通常仍需要睡眠，能够接受反馈，也能合理评估风险。躁狂会改变情绪、活动水平和判断力，严重时可能伴随妄想或幻觉。[R05] 如果出现睡眠需求显著下降、精力持续上升和危险决策，应尽快接受精神科评估；恢复前避免重大财务、职业和关系决定。

### 8. 精神病性症状

- 听见别人听不到的声音，或看见别人看不到的事物。
- 坚信自己被监控、迫害、控制或正在接收特殊信息。
- 语言突然难以理解，思维明显混乱。
- 行为变得异常、不可预测。
- 自理、卫生、学习或工作能力突然下降。
- 明显难以区分现实与想象。

重点不是想法是否少见，而是现实检验能力是否受损。严重睡眠剥夺、处方药、酒精或其他物质、神经系统疾病也可能导致类似表现。新出现或迅速加重时，需要及时医疗评估。[R06]

### 9. 解离表现

- 感觉自己像在旁观身体或行为。
- 环境像梦境、不真实或隔着一层东西。
- 出现无法用普通遗忘解释的记忆空白。
- 强烈压力下感觉时间断裂或身份感模糊。

短暂发呆不等于解离障碍。疲劳、惊恐、创伤、睡眠不足、癫痫和物质使用等都可能产生类似体验。

### 10. 注意力与执行功能

- 难以开始和完成任务，经常遗失物品或忘记约定。
- 时间估计明显失准，容易被外界或内部想法打断。
- 冲动插话、难以等待。
- 只有在高兴趣或高压力下才能集中。

成人 ADHD 通常需要儿童期开始、跨场景持续存在的证据。近期才出现的注意力问题，应优先考虑睡眠、焦虑、抑郁、压力、物质使用和身体疾病。

### 11. 饮食与身体形象

- 极端限制饮食、长时间禁食，或暴食时明显失控。
- 催吐、滥用泻药或以过量运动补偿。
- 体重和外形几乎决定自我价值。
- 因害怕进食或被看见进食而回避社交。
- 出现头晕、晕厥、心悸、月经变化或明显消瘦。

进食障碍可以发生在任何体重。正常体重不能排除危险；晕厥、脱水、胸痛、呕血等需要立即就医。

### 12. 酒精、药物与行为成瘾

- 使用量不断增加才能获得相同效果。
- 想减少却反复失败，或用其入睡、逃避情绪、维持工作。
- 使用后影响工作、人际、财务或安全。
- 隐瞒使用量。
- 停止后出现手抖、出汗、失眠、焦虑等戒断表现。
- 赌博、游戏、色情或购物失控，并持续造成损失。

WHO 的 AUDIT 用于识别危险及有害饮酒和可能的依赖，但不能替代临床评估。严重酒精依赖者突然自行停酒可能有危险，应先咨询医生。[R07]

### 13. 睡眠问题

记录入睡、夜醒、起床、实际睡眠时长、白天困倦、打鼾憋醒，以及咖啡因、酒精和药物使用。尤其要区分：

- 想睡但睡不着：常见于失眠、焦虑等。
- 睡得少但完全不困：需警惕躁狂或轻躁狂。
- 睡了很久仍疲乏：需考虑睡眠呼吸暂停、抑郁或身体疾病。

## 四、用 5P 模型理解问题背后的因素

症状名称只是表面。个案概念化更关心症状为什么在此时出现，又为什么持续。

### 1. Presenting：当前问题

- 具体症状是什么，从什么时候开始？
- 哪些场景最严重，最近如何变化？
- 对学习、工作、自理和关系有什么影响？
- 当前最大的安全风险是什么？

### 2. Predisposing：易感因素

易感因素不是命运，只表示脆弱性可能增加：

- 家族精神障碍、成瘾或自杀史。
- 童年长期忽视、虐待、霸凌或家庭冲突。
- 长期身体疾病、神经系统疾病或慢性疼痛。
- 高度完美主义、低容错，自我价值过度依赖成绩。
- 长期缺乏稳定支持。
- 既往相似发作史。

### 3. Precipitating：诱发因素

寻找症状开始前数周至数月的变化：

- 失恋、丧亲、人际破裂。
- 工作或学业压力、失败、角色变化。
- 搬家、毕业、失业、经济危机。
- 疾病、手术、生产或激素变化。
- 睡眠节律被打乱。
- 开始、停止或调整药物。
- 酒精、娱乐性药物或兴奋剂使用变化。

### 4. Perpetuating：维持因素

- 回避让焦虑短期下降，却让恐惧长期保留。
- 反刍、自责和反复复盘。
- 不断寻求保证，无法容忍不确定性。
- 昼夜颠倒、缺乏活动。
- 用酒精、游戏、购物暂时麻醉。
- 长期超负荷工作，没有恢复时间。
- 完美主义导致“做不到最好就不开始”。
- 关系中的批评、控制、暴力或长期不稳定。
- 债务、骚扰、疾病等现实问题没有得到处理。
- 把所有不适解释成个人缺陷。

### 5. Protective：保护因素

- 至少有一个可以联系的人。
- 有稳定住所和基本经济安全。
- 能维持基本作息和自理。
- 有重要关系、责任、价值或长期目标。
- 知道过去哪些应对方式有效。
- 愿意求助和接受反馈。
- 能够获得医疗、心理和社会支持。

保护因素不能抵消明确的自杀计划，但会影响后续安全和支持方案。

## 五、标准化量表怎样使用

建议“少而精”，不要一次做十几种网络测试。

| 目的 | 常用工具 | 使用边界 |
|---|---|---|
| 整体幸福感 | WHO-5 | 适合观察趋势，不诊断疾病 |
| 抑郁症状 | PHQ-9 | 回顾近两周；第 9 题涉及死亡或自伤时需单独评估 |
| 广泛焦虑 | GAD-7 | 回顾近两周；不能覆盖所有焦虑障碍 |
| 失眠 | ISI | 评估失眠严重程度及其影响 |
| 酒精问题 | AUDIT 或 AUDIT-C | 阳性提示进一步评估，不等于酒精依赖 |
| 创伤后症状 | PC-PTSD-5 | 仅适用于存在创伤暴露者 |
| 成人 ADHD | ASRS-v1.1 | 阳性后要核实儿童期和跨场景证据 |
| 饮食问题 | SCOFF | 高敏感简筛，不能确认具体诊断 |
| 双相线索 | MDQ | 假阳性可能较多，不能脱离完整病史下结论 |

正确用法：

1. 使用经过正式翻译和验证的版本。
2. 固定量表规定的回顾时间窗口。
3. 在相似条件下重复，例如每两周一次。
4. 观察趋势，不迷信单次总分。
5. 把结果与睡眠、现实事件和功能变化一起看。
6. 阳性表示“值得进一步评估”；阴性也不能推翻明显症状。

PHQ-9 和 GAD-7 分别经过原始验证研究，但本质上仍是筛查和严重程度工具，不是独立诊断程序。[R08][R09]

## 六、必须排除的身体、药物和物质因素

心理症状不一定全部来自心理原因。初次出现、突然恶化或表现异常时，应向医生说明：

- 甲状腺、贫血、感染、血糖和营养问题。
- 睡眠呼吸暂停、癫痫、偏头痛和脑外伤。
- 慢性疼痛和其他长期疾病。
- 激素变化、妊娠、产后和围绝经期。
- 咖啡因、尼古丁、酒精、大麻及其他物质。
- 激素、兴奋剂、减肥药、部分感冒药和其他处方药。
- 最近是否开始、停止或调整精神科药物。

不要根据自查结果自行开始、停用或改变处方药。

## 七、14 天观察方法

每天固定时间记录一次：

| 项目 | 记录方法 |
|---|---|
| 睡眠 | 入睡、醒来时间，估算实际总时长 |
| 情绪 | 低落、焦虑、易怒分别记 0—10 分 |
| 精力 | -5 表示极低，0 表示平时，+5 表示异常旺盛 |
| 兴趣 | 是否完成一件原本重视的活动 |
| 身体 | 食欲、疼痛、心慌、胃肠反应 |
| 思维 | 反刍、担忧、注意力和异常体验 |
| 行为 | 回避、冲动、饮酒、消费和争吵 |
| 功能 | 学习、工作、自理、人际分别记 0—10 分 |
| 事件 | 当天主要压力源及发生时间 |
| 应对 | 做了什么，短期和数小时后的效果 |
| 安全 | 有无自伤、死亡或伤人想法 |

记录可观察事实，例如“凌晨 3 点入睡，缺席上午会议”，不要只写“我越来越废”。两周后重点看趋势、反复出现的触发因素和功能变化，不要只计算平均分。

## 八、什么时候寻求哪种帮助

### 可以短期观察

- 症状较轻，有明确的短期诱因。
- 功能基本完整。
- 没有安全风险、躁狂或精神病性症状。
- 通过休息、解决现实问题和社会支持正在改善。

观察不是无限等待。若症状持续、加重或反复损害功能，应进入专业评估。

### 建议预约心理咨询或临床心理评估

- 症状持续存在或反复发生。
- 明显存在回避、反刍、完美主义或关系模式等维持因素。
- 对学习、工作或关系产生稳定影响。
- 自己尝试调整但效果有限。
- 希望系统理解情绪、认知和行为模式。

选择能够说明专业资质、工作方法、费用、保密范围和危机处理边界的从业者。

### 建议到精神科或精神心理科

- 症状达到中度以上或出现显著功能损害。
- 怀疑双相障碍、精神病性症状、严重强迫、创伤或进食障碍。
- 存在自伤、攻击、严重冲动或物质依赖。
- 需要鉴别身体疾病、药物和物质因素。
- 可能需要药物治疗、医学检查或正式诊断。

### 需要立即求助

- 出现第一章中的危机信号。
- 本人无法保证安全。
- 症状在数小时至数日内快速恶化。
- 家人或同住者已无法维持安全照护。

## 九、如何带着自查结果就诊

准备一页信息即可：

1. 最困扰的三个症状及开始时间。
2. 睡眠、精力、情绪和行为相对平时的变化。
3. 对学习、工作、自理和关系的影响。
4. 是否出现自伤、死亡、伤人想法或异常感知。
5. 既往类似发作、治疗和用药情况。
6. 当前所有药物、补充剂、酒精及其他物质使用。
7. 重要身体疾病和家族精神疾病史。
8. 最近的重大事件，以及能够提供支持的人。

不要为了“符合某种疾病”筛选信息。互相矛盾的信息、症状波动和不确定性本身都有诊断价值。

## 十、最容易出现的自查错误

- 把量表分数当成诊断结论。
- 只看心理解释，不排除身体、药物和物质因素。
- 只看痛苦，不看功能损害和危险行为。
- 把长期人格特点误认为近期发作，或反过来。
- 只查抑郁，遗漏躁狂、精神病性症状和物质使用。
- 因一次好转否认长期问题，或因一天糟糕认定自己患病。
- 用自查替代求助，反复测试却不采取行动。
- 用网络标签解释亲友，为别人作临床诊断。

系统自查最终应形成一份可以核验的描述：何时开始、出现什么、持续多久、损害什么、由什么诱发和维持、有哪些风险与保护因素。它的价值在于提高求助和判断的质量，而不是让人更自信地给自己贴标签。
